# 🐍 Python - Яндекс Практикум

Репозиторий с решениями задач из курса **"Основы Python"** от [Яндекс Образования](https://education.yandex.ru/handbook/python).

## 📚 О курсе

**Основы Python** — это комплексный курс от Яндекс Образования, который шаг за шагом разбирает устройство языка: от типов данных и методов примитивов до нюансов объектно-ориентированного программирования и работы с памятью.

### Что охватывает курс:

1. **Введение** — знакомство с Python и настройка среды разработки
2. **Базовые конструкции Python** — ввод/вывод, условные операторы, циклы
3. **Коллекции и работа с памятью** — строки, списки, словари, множества, работа с файлами
4. **Функции** — области видимости, лямбда-функции, декораторы, генераторы
5. **ООП** — классы, наследование, исключения, модули
6. **Библиотеки** — math, numpy, pandas, requests

## 🔧 Инструменты разработки

Проект настроен с современными инструментами для поддержания качества кода:

- **Pre-commit hooks** — автоматические проверки перед коммитом
- **Ruff** — быстрый линтер и форматтер Python
- **GitHub Actions** — автоматическое обновление прогресса в README

### Установка pre-commit

```bash
pip install pre-commit
pre-commit install
```

### Обновление прогресса вручную

```bash
python .github/scripts/update_progress.py
```
